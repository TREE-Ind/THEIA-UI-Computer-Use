# Runtime scope and validation

This publication contains the accessibility adapter, structured error and stage guidance, grounding/ROI safeguards, bounded resident prefetch, exact region dirty tracking, semantic verification, automatic RGB acquisition, frame transport, freshness/quarantine recovery, and optional closed-candidate System One decisions and bounded public navigation.

Accessibility metadata is not action authority: unmapped driver geometry remains metadata and requires native visual grounding. The installed public driver contract is checked, child environments are sanitized, and an unavailable sanitizer fails closed. Crop `found` alone is insufficient authority; broader immutable context or an independently bound trusted witness is required. Verification distinguishes changed pixels from semantic completion. Optional Jev calls send text metadata only and require public-context opt-in; missing credentials do not silently select another model.

Native candidate validation, encoder benchmark/profile, custom-kernel activation, their registration/schema/lifecycle machinery, artifacts, binaries, weights, local receipts and private captures are excluded. Generic worker freshness, quarantine and recovery remain. There is no native maintenance reservation or benchmark tool in this surface.

Run the full source suite with `uv run --no-project --with pytest --with pillow --with pyyaml python -m pytest tests -q` and use a profile scratch `--basetemp` if needed. Tests use synthetic captures/transports; workspace admission additionally performs actual network-backed uv resolution. It reproduces the old unselected-transformers-extra conflict, then admits core huggingface-hub 1.24.0 with the isolated plugin metadata. It downloads neither models nor Torch and uses no GPU.

Optional scripts are not run automatically. `verify_ax_daemon.py`, `verify_speed_cua.py` and `verify_speed_safety_api.py` require installed Hermes/CUA and create a public test-owned Tk fixture. They write local reports under ignored `artifacts/`; these reports are not published. `verify_frame_pipeline.py --report <scratch-report-path>` acquires the active window and owns/closes a worker: run only with explicit capture authorization, a public fixture, and no competing THEIA GPU owner. Source tests and clean install do not establish live activation, GUI acceptance or generalized speed/accuracy gains. Cached pass timings may be historical; inspect current total timing and cache-hit fields.
